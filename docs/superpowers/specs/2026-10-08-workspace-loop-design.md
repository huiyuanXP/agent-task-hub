# 点子工坊：本机闭环与多 workspace 接入设计

状态：等待用户审阅；尚未实现本设计。

## 目标和验收口径

用户在网页报点子或 Ticket，常驻 Agent 生成规划，在用户确认执行范围后处理指定 workspace 的任务，网页展示进度、变更、测试和验收结果。
点子工坊首先服务自己的改进；随后以同一个客户端安装包接入其他 workspace。
主后台管理当前账户授权并注册的全部客户端，不声称发现未安装、未注册或其他账户的 MCP。

完整验收必须使用实际下载的包，在新建 Git 测试项目安装 MCP，完成真实协议交互和客户端注册，并在浏览器看到在线记录。
真实 AI 模型调用、文件变更和实际测试必须另有证据；测试模型或协议模拟不能替代真实 Agent 验收。

## 分为三个可独立验收的子项目

1. [连接、授权与安装](2026-10-08-workspace-connections-design.md)：安装包、MCP 适配器、注册、心跳、撤销和后台连接页。
2. [规划与开发执行](2026-10-08-workspace-agent-design.md)：真实本机 Agent、任务租约、工作区执行、持久进度和结果证据。
3. [网页闭环与验收](2026-10-08-workspace-acceptance-design.md)：点子/Ticket 到结果的操作流程及从下载包开始的安装验收。

先收尾既有本地基础，再按上述顺序实现；每个子项目独立检查，最终合并验证整个链路。

## 用户流程

1. 进入“连接与执行”，为一个明确命名的项目创建连接邀请；选择规划、报单或执行能力。
2. 下载客户端包，或者复制界面给出的安装命令；本机 Agent 也可读取安装说明并运行相同安装器。
3. 安装器以授权码换取专属凭据，关联项目、连接与本地仓库；安装 MCP 后主动测试协议并注册。
4. 常驻 Agent 启动后发送心跳；后台分别显示 MCP 最近使用状态和 Agent 执行可用状态。
5. 用户保存点子；规划 Agent 领取该修订，回写 Plan 和 Tickets。直接报 Ticket 则进入待规划/待确认的开发入口。
6. 用户查看目标 workspace、任务范围和计划，批准开发执行；没有批准的任务保持等待。
7. Agent 在该仓库的独立 Git worktree 修改、运行检查，持续回报进度和等待原因。
8. 网页展示变更摘要、实际 diff、测试命令/退出码、产物和执行日志；用户验收或要求返工。
9. 工坊自身的改进也走同一流程；验收完成后更新本地预览，保留数据库和已有点子。

## 边界和既有授权

用户已授权在本机开发、安装测试客户端、创建测试项目和验收；既有“不要执行用户生成 Ticket”的开发限制在此次明确授权范围内被更新。
任务执行批准与安装授权分别记录；安装一个 MCP 不自动批准当前及未来全部 Tickets。
开发交付首先产生本地可检查的变更和测试结果；网页部署更新、远程合并、push 或发布以任务明确批准的操作范围为准。
不能把宿主开发执行包装成已通过 Docker 隔离的运行；新增本机开发能力须明确显示其运行方式和实际限制。
不复制模型凭据到网页、工坊数据库或下载包；客户端使用本机已配置的模型登录。

## 全局技术要求

- Node.js >=22.23.3，原生 Next/React 和 SQLite；保留现有版本、锁文件、所有业务数据及 owner 边界。
- 所有新表使用追加的 checksum 跟踪 SQL migration；不改写已应用迁移。
- 默认监听 loopback；网页通过当前 HTTPS 隧道访问；客户端使用配置的 canonical URL。临时隧道变化需允许更新服务地址和重新验证，不能清空客户端状态。
- 浏览器请求保留 Host/Origin 校验；专属客户端凭据走明确的机器认证分支，不伪装成浏览器 session。
- 凭据、授权码、仓库本地路径、原始模型环境变量不写进通用日志或下载包；凭据文件权限 0600，目录 0700。
- 新增真实行为均纳入中文 FEATURES 和当前架构文档；不保留旧运行环境作为第二套入口。
- 先完成构建，再运行使用该构建的 HTTP/浏览器测试；更新预览时有序停止服务，避免正在运行时修改共享 `.next`。

## 最终交付证据

- 下载包 SHA-256、版本、安装命令及退出码。
- 测试项目注册 ID、后台可见连接 ID、协议初始化/工具调用结果。
- 启动、停止、离线、重连、撤销的实际状态记录。
- 一条实际点子生成 Plan/Tickets 的证据和一条直接报 Ticket 的证据。
- 一条真实批准的开发任务、worktree diff、实际测试输出、结果回写及网页验收证据。
- 否决/撤销/跨项目/重复领取/重启恢复检查，无伪造在线、模型或执行成功。
- 真实模型认证缺失时明确记录阻塞，仅报告实际完成的安装/协议/管理检查。
