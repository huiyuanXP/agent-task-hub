# 子项目一：连接、授权与安装

状态：用户已批准；约束继承 workspace-loop-design。

## 数据和权限

新增项目/workspace、连接邀请、客户端连接、短期会话和连接事件表，均绑定 owner。
项目 ID 为稳定标识，页面的文本 project 名称作为显示值；不同 owner 的同名项目不互通。
现有点子保留原文和修订；已有“通用”项目可由 owner 显式关联 workspace，不在安装时静默迁移所有任务。
连接记录包含项目、客户端 ID、名称、安装版本、声明能力、最近验证的能力、最后成功通信时间、错误摘要和撤销时间。
绝对仓库路径只由客户端本地配置持有；服务端只显示名称、仓库标识或脱敏路径，不接受远程任意路径作为执行指令。

## 授权和注册

网页登录账户创建邀请，指定项目和能力：报点子/Ticket、读取本项目、规划本项目、执行本项目。
一次性邀请授权码使用 32 字节随机数，数据库只存 hash，10 分钟过期；兑换必须原子消费，重复兑换拒绝。
兑换生成独立客户端身份及专属可撤销凭据；不向客户端下发账户全权限 API token。
凭据有效期 30 天，支持 owner 撤销和到期重新授权；撤销立即阻止工具调用、领取和续租。
下载说明不包含有效 token；复制命令默认将授权码通过交互输入或 stdin 传入，避免命令历史记录。
项目绑定和能力仅能由 owner 修改，客户端自报 capabilities 不能扩权。

## 包、CLI 与 MCP

提供真实可下载、带版本和 checksum 的 Node 客户端归档，包含 CLI、STDIO MCP 适配器、README 和安装检查。
CLI 子命令：安装/关联、诊断、MCP 服务、常驻 Agent、更新服务 URL、撤销本机配置。
安装器校验 Node 版本、服务 URL、授权码、目标 workspace 和已有客户端配置；保留用户已有 MCP/Agent 配置，只增量添加命名条目。
MCP 采用标准 JSON-RPC 生命周期，支持初始化、notifications/initialized、ping、tools/list、tools/call 和正确错误语义；STDIO 的 stdout 仅写协议消息。
本机 Codex 使用官方 STDIO MCP 配置方式安装，其他客户端可复制通用 command/args 配置。
本地适配器绑定一个项目，仅暴露授予的工具；兼容现有工坊规划/读取能力，新增直接报 Ticket 的接口。
服务端机器端点使用客户端身份；原有 `/mcp` owner 工具继续保留，但不把 owner 凭据嵌入客户端。
客户端不需要开放 inbound 端口，远程 workspace 使用 outbound HTTPS 拉取任务和发送心跳。

## 在线状态

常驻进程每 15 秒心跳，最近 45 秒内视为在线；45–90 秒为连接延迟，超过 90 秒为离线。
按服务端接收时间判定状态；心跳包含运行模式、客户端版本和受验证的 Agent 可用性。
只有 MCP 短进程而无 daemon 的客户端显示“已安装／最近使用”，不声称一直在线。
MCP 工具调用、诊断和 daemon 心跳分别留事件，后台可查看连接详情、任务和错误。
同一安装重启保持稳定 ID；卸载或撤销保留历史，禁止重复注册制造假在线记录。

## 独立验收

用网页下载的包安装到新测试 Git 项目；通过实际 STDIO 初始化并调用报点子或查询工具；后台能看到该项目与客户端。
验证心跳超时、重启恢复、凭据撤销、邀请重放拒绝及跨 owner/项目访问拒绝。
使用真正的客户端进程验证，不以数据库插入假连接替代安装。
