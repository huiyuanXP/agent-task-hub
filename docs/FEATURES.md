# 点子工坊功能

## 账户与工作区

- 使用本机创建的账户登录，浏览器 session 到期或退出后清除当前页面的私有状态。
- 将业务记录保存在本地 SQLite，并通过修订冲突与历史快照保护已有内容。
- 按项目筛选工作区中的点子、Plan、Tickets 和执行记录。

## 点子收件箱

- 保存点子原文、标题和项目，并为当前修订创建持久规划请求。
- 修改点子会产生新修订和规划任务，同时保留旧计划及其来源信息。
- 展示规划排队、租约、恢复、失败原因和可用的重试操作。

## 规划工作台

- 展示目标、范围、验收、假设和与原始点子的关联。
- 使用项目 Agent 的专属领取 token 原子回写 Plan 和最多三十个稳定逻辑 key 的 Tickets。
- 查看规划生成的 Tickets，或从 Plan 手工创建新的 Ticket。

## Ticket 看板

- 创建和修改 Ticket 的目标、范围、验收、状态、优先级及等待原因。
- 用看板或列表查看待开始、进行中、等待、完成和错误任务。
- 为指定项目 workspace 申请开发执行，冻结 Ticket 修订与期限并记录批准或拒绝。
- 为登记的固定 Docker 操作单独申请资源预算和范围受限的执行授权。

## 待我处理

- 汇集需要澄清、审批、验收或外部条件的 Tickets。
- 查看本机开发任务的待批准、失败和待验收结果，并执行批准、取消、验收或返工操作。

## 执行记录

- 保存手工执行快照的冻结 Ticket 和填写的证据，同时明确标记它是手工记录。
- 展示真实本机开发 Run 的进度、Agent 总结、实际 diff、修改文件及测试命令和退出码。
- 保留固定 Docker 后端的真实状态、签名结果、取消与停止收据以及受限产物下载。
- 在 owner 验收开发结果后更新 Ticket 完成状态，并保留先前的修订和执行证据。

## 连接与执行

- 为指定项目和能力生成短期一次性安装授权码。
- 点击下载独立的 MCP/CLI 客户端包，或读取网页和 JSON 安装指南。
- 安装器将项目关联到工坊并写入增量 MCP 配置，不覆盖其他连接。
- 使用 STDIO MCP 提交点子或 Ticket，以及读取、领取和回写被授予的本项目任务。
- 常驻 Agent 使用 outbound 请求领取任务并发送心跳，模型认证保留在安装机器上。
- 查看注册客户端的项目、版本、能力、最近通信、所选 Profile/模型/provider、就绪状态及最近事件。
- 区分 MCP 最近使用、常驻进程在线、延迟、离线和已撤销状态。
- 撤销客户端后拒绝后续工具调用、任务领取和续租，同时保留连接历史。

## 后台机制

- 本机进程定时维护规划投递、失效租约与有限恢复，而不依赖浏览器持续打开。
- 通过本地账户和项目专属客户端身份隔离数据，拒绝伪造身份及跨项目访问。
- 通过批准范围、修订绑定、有限租约和受管进程记录约束本机开发执行。

priority、queue、budget、cadence 等可填写文本字段仅在对应执行或调度接口明确使用时构成实际运行约束。
