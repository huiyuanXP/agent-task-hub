# 后续工作

当前主线是可安装的项目 MCP、真实连接监控、点子规划、本机开发执行与网页验收。实现与实际验证范围以代码和验收记录为准，未认证的模型或未接通的后端不能标成完成。

下一步按使用反馈推进：更多 Agent 客户端安装方式、稳定远程服务地址、长期进程托管、运行日志保留和备份恢复、复杂依赖调度、周期任务、成本与模型额度管理。

远程 PR 合并、发布和部署需要具体 Ticket 中明确的操作范围与验收证据。执行队列、priority、cadence 等文本属性只有接入真实调度后才形成运行约束。

当前从“通用”项目的已批准 Run 推进详情信息分组，后续按 Ticket 依赖处理详情交互、
共享项目目录、执行入口、排序和拖动。直接 API Call 模型接入与认证作为独立工作项；
本机支持 Codex 默认配置、已有 API 网关和命名 Profile。

执行边界的后续修复包括：到期 Run 在确认受管进程完全退出后释放物理占用，
以及将独立 TypeScript 检查纳入 Agent 的实际检查回执识别。
